# Forge 1.12.2 Template
Powered by **RetroFuturaGradle** and **Gradle 9+**

## Setup
1. Click **Use this template**.
2. Rename across the project:
   - `ExampleMod` → Mod Name (e.g., `TerraTools`)
   - `examplemod` → Mod ID (e.g., `terratools`)

## Building
Requires **JDK 17+**. Output is saved to `build/libs/`.

### Windows
```powershell
.\gradlew.bat assemble
```

### Linux / macOS
```bash
./gradlew assemble
```
